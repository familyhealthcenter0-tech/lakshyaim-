=== PROJECT SUMMARY ===

Project: Lakshyaim Private Limited

Type: Healthcare/Nutrition E-commerce Website

Live URL: https://future-academy-80ae5.web.app

GitHub: https://github.com/familyhealthcenter0-tech/lakshyaim-

Admin Login: admin / admin123 (demo)

Theme: Deep Blue (#1e40af) + Orange (#f97316) - Shopify inspired

PWA: Enabled with install prompt, popup, FAB, footer button, service worker, manifest

Chatbot: Bilingual (Hindi/English) product expert in footer

Key Features Implemented

1. Homepage with hero, products, gallery, testimonials, FAQ, membership

2. Dedicated pages: Products, Gallery, Cart, Checkout, My Orders, Product Detail, Invoice

3. Add to Cart system with qty steppers, free shipping progress

4. Google Authentication (Firebase Auth) for checkout

5. Admin Panel with 10 views: Dashboard, Products, Orders, Analytics, Gallery Manager, Database, Members, Content CMS, Activity Log, Settings

6. Admin Settings: Logo, Shipping, GST (18%), Payment (Razorpay only), Social Media, Company Details, Admin Credentials

7. Razorpay Payment Gateway integration (direct payment on Place Order)

8. Professional Invoice system with GST breakdown, company details, print support (single page)

9. Product Detail pages with description, benefits, ingredients, usage

10. Dark/Light mode toggle on all pages

11. PWA support with install prompt, popup, FAB, footer button, service worker, manifest

12. Saved address feature in checkout

13. Order status tracking (Pending, Paid, Shipped, Delivered)

14. Business analytics with 12 KPIs and 7 charts

15. Bilingual chatbot (Hindi/English) with product knowledge base

16. Professional invoice with company logo, address, phone, email, GSTIN

Technology Stack

HTML5, CSS3, JavaScript (ES6+), Firebase Hosting, localStorage, Razorpay Checkout SDK, Google Fonts (Manrope + Inter), PWA (Service Worker + Manifest)
